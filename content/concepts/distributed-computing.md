# [Concepts](/concepts/) / Distributed computing

Distributed computing is a [distributed](/concepts/distributed/) system typified by a collection of computing resources that share neither a common physical clock nor memory, and are usually separated geographically with [autonomy](/concepts/autonomy/) and heterogeneity.

[Distributed ledgers](/concepts/distributed-ledger/), of which [blockchains](/concepts/blockchain/) are the most famous, are considered distributed computing systems, although each node can hardly be declared wholly autonomous (i.e. nodes must follow very strict code).

When the system architecture treats participants as equals, as equipotent, both able to call for and provide services and resources, the distributed system is described as peer-to-peer.
